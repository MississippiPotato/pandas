# pandas 可视分析工作台

原生 JavaScript + D3.js 的中英双语 **pandas Visual Analysis Workbench**。用可视交互完成 pandas 风格的数据选择、清洗、统计和变换；支持自定义表格，以 NBA 球员逐场表现作为统一示例主题。**固定浅色界面**。浏览器使用 JavaScript 计算，等价 pandas 代码供导出复现；没有 Python 后端或上传服务。

访问：[GitHub Pages](https://MississippiPotato.github.io/pandas/) · [源代码](https://github.com/MississippiPotato/pandas)

问题引导、工作台与通用导入改版已部署，运行提交为 `8e29a9b`；状态与历史记录见 [交付记录](docs/DELIVERY.md)。

## 可以做什么

- **分析故事 `#/overview`**：从“一场高分，就能说明一切吗？”开始，提供一条明确的五步路线。首页不再同时堆叠任务目录、流程说明和多套案例。
- **跟着分析 `#/guide?step=0`**：认识记录 → 处理缺失 → 筛选出场 → 观察滚动走势 → 比较球员。每页一个问题、一个主要图形、少量参数和一个下一步按钮；代码、明细与差异按需展开。
- **辅助案例（仍可访问 `#/nba`）**：球员、球队、时间与真实投篮空间；选区可正式提交并带到工作台。
- **自由工作台 `#/studio`**：加载与查看、选择与排序、清洗与类型、分组与统计、关联与重塑、时间与窗口。方法和解释直接可见；详细参数/限制可展开，配置自动更新预览及等价代码。
- **.plot() 图库**：11 种图形已融入工作台图表选择器与图库弹窗；旧 `#/gallery` 自动进入工作台。

23 个注册变换：`filter`, `sort`, `dropna`, `fillna`, `dedup`, `cast`, `rename`, `select`, `derive`, `group`, `pivot_table`, `pivot`, `merge`, `concat`, `rolling`, `resample`, `cut`, `qcut`, `rank`, `cumsum`, `transform`, `melt`, `date_part`。异常值检查通过显式 IQR 筛选调用同一引擎。

工作台先展示“认识数据 → 选择目标 → 配置与预览 → 应用与导出”，根据当前 schema 提供清洗、筛选、分组和趋势四个起点，自动预填当前字段。结果区用图形／数据／统计／代码切换，图形无需藏在整张表格下方；流程、来源、字段细节按需展开。表头刷选、类别点击、Diff 与流程代码仍可使用。

## 自定义数据怎样适配

字段无需改成 NBA 名称。导入走三步：确认结构 → 确认字段类型与用途 → 选择分析起点。支持自动识别逗号、制表符、分号、竖线；设置表头起始行或自动生成列名；XLSX 可选工作表和表头行。文本必须 UTF-8，JSON 必须是扁平对象数组；复杂报表和嵌套 JSON 需先整理成二维表。

金额、数量等设为数值；编号设为标识（可关联、计数、去重，不参与均值）；日期默认严格 ISO，也可明确选择年/月/日、日/月/年、月/日/年顺序，转换错误需修正或明确同意转为缺失。普通大额、唯一的金额不会自动当成 ID。可以记录“一行代表什么”，在工作台随数据保留。若每月一列，可选择 `melt()` 预览转成长表；不是强行重命名成 NBA 字段。导入说明提供通用销售 CSV 模板。

操作、图形与提示随当前字段更新。没有日期时继续清洗、筛选、分组；时间分析明确说明前提；没有数值时仍能按类别计数。完整支持范围见 [功能映射](docs/PANDAS_COVERAGE.md)。

所有变换先预览再提交。分组展示“拆分—计算—合并”、指标与输入样本数；缺失处理展示逐字段前后数量/比例和同坐标分布；关联展示两表、键、匹配、重复键和行数扩张；滚动展示排序后原始值与结果的同图对比。流程步骤显示任务与 pandas 方法，可查看参数、变化、图形和代码。

图形临时选择、尚未确认的配置与已应用数据明确区分；表格、统计和图形查询共享当前范围。CSV 分为已应用结果与临时选区；完整 Python 脚本只导出已应用的依赖流程。对比模式支持删除行、单元格变更与聚合/重塑分屏。操作面板提供缺失率、均值/中位数线、筛选刷选、cut 拖动边界、qcut 边界、连接键重合度和分组样本数控件。

支持分析结果 / SVG / PNG / 流程 JSON / 项目包导出及 IndexedDB 本机保存。支持编辑、撤销、重做、依赖重算；切回源表另开分支后撤销，会返回该分支实际使用的输入。

## 首次使用与演示路线

从首页点击“跟着做一次完整分析”。按左侧五站顺序：先说明一行的含义；在均值/中位数图上选择缺失处理；拖动分钟区间决定比较范围；选择球员和窗口查看原始/滚动得分；最后同时查看场均得分、标准差和样本数。每一步预览都使用上一站的已应用结果，确认后才创建真实 Session 节点。最终可导出 CSV / 可运行 pandas Python，或带着结果进入自由工作台。

最后一站提供得分榜与得分/波动散点两种视图；最低出场数确实写入筛选，不是纯显示选项。散点显示全部符合条件且标准差有效的球员，条形图只显示场均得分前 10 位。滚动窗口按出场次数，筛选后的日期序列计算；不冒称整赛季官方结论。路线仅针对内置 NBA 教学数据，自定义数据仍在自由工作台使用。

开发阶段核对了标题行 + 分号 + DMY 日期的通用导入、缺失填充和分组预览／应用。随后发布 CI 通过 55 项引擎检查、50 组 pandas 对照及 120 项 NBA 数据核验；公网默认五站路线实际走通。上述结果不代表 23 个操作的所有参数组合或所有浏览器状态都已验收。

## 默认数据与刷新恢复

默认是 **NBA 球员逐场缺失练习表 4,784 × 16**，并提供同规模的**原始值对照表**、球队关联表 **30 × 5**、月度球员宽表 **475 × 12**。首页围绕同一 NBA 主题提供可直接配置并预览的清洗、关联、近五次出场、球队贡献任务。Titanic **891 × 9** 作为可选通用性验证表，原始 NBA 逐场与投篮坐标仍可加载。

练习表按固定身份哈希，移除 **241 个 fg_pct、357 个 minutes、128 个 pts** 单元格，未改动其他值或行。**这是用户授权的教学缺失副本，不是官方数据缺失情况。** 页面有明确标识，可随时切回原值或下载逐单元格[移除清单](public/data/examples/nba-missing-audit.json)。原始 position 空白表示来源未记录首发位置，不能当成球员位置事实来填造。

NBA 只描述真实的 **2025 年 11 月**。比赛日期、重复出场球员、可读球队/对手、比分派生胜负支持同一主题内的筛选、关联、清洗、统计、透视、滚动、分箱和排名；不依赖薪资、市值等不在此来源中的字段。Titanic 保留自然缺失。[来源及哈希](public/data/examples/manifest.json)。

`#/studio?table=nba_missing`、`#/nba?tab=team` 可直接打开相应状态。为支持导入表与派生步骤刷新，当前流程及源数据会自动暂存在本机 IndexedDB 的独立导航槽位，手动保存项目仍独立；“清除本机保存”清除两者。文件不上传。缓存不可用时本次分析仍能继续，但刷新恢复受限。

## 数据范围与语义

默认数据是 **2025 年 11 月常规赛有限历史快照**：219 场、30 队、498 名名单球员、5,698 条球员比赛名单记录（4,784 条实际出场）、438 条球队逐场记录、39,092 次投篮。不是整赛季、实时或生涯统计。

来源：SportsDataverse，上游 NBA.com/Stats。六张规范表、字段类型、资产 URL、字节数与 SHA-256 位于 [manifest](public/data/nba/2025-26-nov/manifest.json)。3 场 NBA 官方计分员 PDF 抽查共 81 项数值匹配；不代表逐条独立验证所有记录。

投篮球场叠加按 SportsDataverse 定义：单位 0.1 英尺，篮筐原点，不再次翻转主客方向。保留负坐标、原点与 6 次越过半场的投篮。点图最多显示 5,000 个确定性样本并保留边界/远投；区域统计、筛选与导出仍使用全量。缺失矩阵最多展示前 80 行/40 字段，类别条形图展示前 15 组，完整结果可导出。

SportsDataverse README 有 CC BY 4.0 标记，其软件 LICENSE 为 MIT；NBA 上游数据适用范围尚有单独条款。**再分发适用范围仍标记 `pending-upstream-review`**；教学用途与可下载事实不等于 NBA 授权。来源与核验边界见 [数据核验](docs/DATA_VERIFICATION.md)，网站说明中也保留披露。

## 实现边界

单次导入 ≤50 MiB、≤100,000 行、≤200 字段、≤5,000,000 单元格。CSV / TSV 使用严格 UTF-8；JSON 只接受扁平记录数组；XLSX 读取所选非空工作表及公式缓存值，不执行 Excel 公式，不支持旧 `.xls`。

这不是完整 pandas 兼容层。只支持白名单参数和安全表达式；不支持任意 Python/UDF、通用 MultiIndex、横向 concat、偏移/居中窗口或本地 DST 日历。滚动窗口按行，日期按 UTC，标准差默认 `ddof=1`。等频分箱的导出脚本明确重放记录的边界，避免浮点边界与原生 `pd.qcut` 的差异；透视结果使用显式平列辅助函数。

## 结构与验收

```text
src/core/       纯函数、统计、操作注册、Session / DAG / 历史、pandas 代码
```
